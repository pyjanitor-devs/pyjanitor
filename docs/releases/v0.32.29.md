# Version v0.32.29

This release focuses on improving data cleaning consistency in the Polars integration by addressing issues with name formatting.

## New Features

_No new features were added in this release._

## Bug Fixes

- Fixed an issue in the Polars integration where multiple consecutive underscores in column names were not properly collapsed into a single underscore when using `make_clean_names`. Now, every run of underscores is collapsed, resulting in cleaner and more consistent column names. (563c5d) (Rodrigo Stachlewski Palma)
