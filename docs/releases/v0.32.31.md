# Version v0.32.31

This release delivers a major overhaul of conditional join and aggregation operations, integrating Rust-based kernels for significant performance and compatibility improvements. It also ensures better dtype preservation for object columns, especially in anticipation of pandas 3.0 changes. Extensive test coverage and documentation updates accompany these enhancements.

## New Features

- Integrated Rust-based kernels for single and multi-condition conditional joins, including support for not-equal and extended join predicates, improving performance and reliability. (a8fe2a, Samuel Oranyeli)
- Routed range-based and dual-range conditional joins through canonical Rust APIs, unifying join logic and enabling more efficient execution paths. (a8fe2a, Samuel Oranyeli)
- Added support for conditional join aggregations using Rust kernels, including fused aggregations and comprehensive edge case handling for nulls, duplicates, and various numeric types. (a8fe2a, Samuel Oranyeli)
- Introduced explicit aggregation kernel registries and improved dtype contract alignment for aggregation results. (a8fe2a, Samuel Oranyeli)
- Expanded regression and edge case test coverage for all conditional join and aggregation scenarios, including nullable and boundary cases. (a8fe2a, Samuel Oranyeli)
- Documented all new join and aggregation contracts, including Python-Rust integration details and join algorithm semantics. (a8fe2a, Samuel Oranyeli)
- Updated janitor-rs integration to version 0.6.2, ensuring compatibility with the latest Rust backend. (a8fe2a, Samuel Oranyeli)

## Bug Fixes

- Fixed an issue where object-dtype columns (e.g., string columns) in conditional join results were incorrectly inferred as the new pandas 3.0 string backend, ensuring dtype preservation consistent with `pd.merge`. (a8fe2a, Samuel Oranyeli, Claude Sonnet 5)

## Deprecations

- Documented the deprecation of Numba-based conditional join dispatch, with all new conditional join logic now routed through Rust kernels for improved performance and maintainability. (a8fe2a, Samuel Oranyeli)
