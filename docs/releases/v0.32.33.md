# Version v0.32.33

This release introduces significant improvements to dual range join operations, including the use of cumulative envelopes for more accurate and efficient joins. The multi-range join module has been refactored for clarity, and documentation has been expanded to better explain the new layout and usage patterns. Several bug fixes and normalization improvements are also included.

## New Features

- Added support for cumulative envelopes in dual range joins, improving join accuracy and performance. (6a5940) (Samuel Oranyeli)
- Expanded documentation to explain the multi-range join layout and provide cumulative range examples. (6a5940) (Samuel Oranyeli)
- Added documentation on dual-range anchor selection tradeoffs. (6a5940) (Samuel Oranyeli)

## Bug Fixes

- Fixed normalization of NumPy cumulative datetime bounds in dual range joins. (6a5940) (Samuel Oranyeli)
- Fixed output rows for all-unmatched cases in join_agg operations. (6a5940) (Samuel Oranyeli)

## Deprecations

- No deprecations in this release.
