# Version v0.32.39

This release brings significant performance improvements and enhanced flexibility to interval-overlap joins, especially when combining equality and range predicates. The update also improves consistency in join behaviors and resolves issues with mixed-type object keys.

## New Features

- Optimized equality-led interval-overlap joins: Equality keys followed by range predicates are now routed through specialized kernels for faster index construction and aggregation. The join logic now supports advanced condition ordering, multiple range predicates, and improved handling of duplicate equality-key layouts, including mixed-type object keys. Additionally, join_agg with an equality predicate now omits unmatched keys and returns empty results when appropriate, aligning with get_join_indices behavior. The underlying janitor-rs dependency is updated to v0.6.4. (4fc277) (Samuel Oranyeli, co-authored by Claude Opus 5.5)
