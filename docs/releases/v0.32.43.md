# Version v0.32.43

This release improves the flexibility and correctness of label selection using slices and glob selectors, especially when working with non-string columns and MultiIndex objects. It also includes documentation and test coverage enhancements for these behaviors.

## New Features

- Added support for using glob selectors on non-string columns, allowing more flexible label selection patterns. (2513ad) (Samuel Oranyeli)
- Documented the behavior of using slice(None) to select all labels on any index, clarifying its usage. (2513ad) (Samuel Oranyeli)
- Added end-to-end test coverage for slice(None) selection to ensure consistent behavior. (2513ad) (Samuel Oranyeli)

## Bug Fixes

- Fixed handling of slice(None) so that it correctly selects all labels on any index type, not just string-based indexes. (2513ad) (Samuel Oranyeli)
- Preserved unbounded column slices and exact glob-like labels, ensuring accurate selection in edge cases. (2513ad) (Samuel Oranyeli)
- Preserved exact MultiIndex level labels and improved performance by avoiding unnecessary scans of MultiIndex levels for exact matches. (2513ad) (Samuel Oranyeli)
- Narrowed selector changes to only affect slice passthrough, preventing unintended side effects. (2513ad) (Samuel Oranyeli)

## Deprecations

- No deprecations in this release.
