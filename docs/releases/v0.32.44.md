# Version v0.32.44

This release introduces enhanced flexibility and robustness to conditional joins, particularly around output column selection and projection. It also includes dependency updates and several internal improvements to join behavior and test coverage.

## New Features

- Added support for specifying output_columns in conditional_join, allowing users to control which columns are included in the join result. This includes improved handling of output projection, normalization of selectors, and preservation of tuple and integer label selectors. (f24049, Samuel Oranyeli, co-authored by Claude Opus 5.5)

## Bug Fixes

- Improved handling of edge cases in conditional join projections, including rejecting empty anti-join projections and ensuring consistent naming of anti-join output selectors. (f24049, Samuel Oranyeli)
- Fixed issues with embedded-NUL join regressions in pandas, and updated test coverage to better isolate and xfail known regressions. (f24049, Samuel Oranyeli)
- Updated internal logic to route slice(None) output selection through select_columns, ensuring consistent behavior across different selection scenarios. (f24049, Samuel Oranyeli)

## Deprecations

- No deprecations in this release.

## Dependency Updates

- Bumped prefix-dev/setup-pixi from 0.11.0 to 0.11.2 for improved environment setup reliability. (a61d09, dependabot[bot])
