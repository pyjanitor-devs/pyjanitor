# Version v0.32.45

This release improves the handling of empty selectors in select statements, clarifies their semantics in documentation, and adds additional test coverage for related cases.

## New Features

- Clarified and documented the behavior of empty selectors in select statements, including updates to selector versioning and semantics. (ec4102) (Samuel Oranyeli)

## Bug Fixes

- Fixed an issue where empty select selectors were not properly supported, ensuring correct behavior when no fields are specified. (ec4102) (Samuel Oranyeli)

## Deprecations

- No deprecations in this release.
