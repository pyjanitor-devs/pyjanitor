# Version v0.32.49

This release focuses on improving the consistency and reliability of deprecation warnings throughout the codebase. It also enhances the associated test coverage to ensure future changes do not introduce regressions related to warning handling.

## New Features

_No new features were added in this release._

- Made deprecation warnings consistent across the codebase, ensuring that all deprecated functionality emits standardized warnings. Also improved regression tests to catch duplicate or missing warnings, and removed an unused import in `conditional_join.py`. (5f0b4c) (BALOGUN DAVID TAIWO)

## Deprecations
