# Version v0.32.50

This release includes a bug fix for handling backslashes in column names when using Polars, as well as updates to indirect dependencies for improved security and compatibility.

## New Features

_No new features were added in this release._

## Bug Fixes

- Fixed an issue where backslashes were incorrectly removed from column names in the Polars backend's `make_clean_names` function. Backslashes are now preserved as expected. (755942, Rodrigo Stachlewski Palma)

## Deprecations

_No deprecations were introduced in this release._

## Dependency Updates

- Updated `certifi` from 2026.7.22 to 2026.10.19 for improved certificate support. (fd04b5, dependabot[bot])
- Updated `virtualenv` from 21.11.1 to 21.14.9 for better virtual environment management. (83ea8e, dependabot[bot])
