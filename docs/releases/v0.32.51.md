# Version v0.32.51

This release focuses on improvements to selector validation and the handling of the pandas DataFrame.select method, along with clarifications and documentation updates related to selector migration and deprecation.

## New Features

- Preserved the pandas DataFrame.select method to maintain compatibility and ease migration for users relying on this functionality. (e79c3e) (Samuel Oranyeli)

## Bug Fixes

- Improved validation for empty downstream selectors to prevent errors when no columns are selected. (e79c3e) (Samuel Oranyeli)
- Enhanced validation for resolved empty selectors, ensuring robust handling of selector logic. (e79c3e) (Samuel Oranyeli)

## Deprecations

- Removed deprecated select method registration and clarified the migration path for users, including documentation on select removal behavior. (e79c3e) (Samuel Oranyeli)
