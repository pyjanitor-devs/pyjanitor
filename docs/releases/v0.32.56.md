# Version v0.32.56

This release improves the changelog automation process, ensuring more accurate and reliable release notes generation. Several enhancements and fixes have been made to how changelog entries are rotated, ordered, and validated during automated releases.

## New Features

- Automatically rotate changelog entries during releases to keep the changelog up to date. (934d43) (Samuel Oranyeli)
- Record empty releases and ensure each release is properly documented in the changelog. (934d43) (Samuel Oranyeli)

## Bug Fixes

- Fixed changelog release ordering and improved the accuracy of comparison links. (934d43) (Samuel Oranyeli)
- Added guards to prevent errors when generating changelog comparison links. (934d43) (Samuel Oranyeli)
- Tightened validation for changelog releases to prevent inconsistencies. (934d43) (Samuel Oranyeli)

## Deprecations

- No deprecations in this release.
