# Version v0.32.57

This release focuses on improving the reliability and robustness of the release process, enhancing changelog management, and ensuring correct data ordering in Polars LazyFrames. Several dependency updates are also included to keep the project up to date.

## New Features

- Added safeguards to prevent changelog entries from being misassigned to the wrong release, including validation across the full release range and improved handling of changelog history. (60ba4a) (Samuel Oranyeli)
- Made auto-release retries recoverable, improving the resilience of the release process and fixing artifact handling during retries. (639ace) (Samuel Oranyeli)

## Bug Fixes

- Hardened the auto-release workflow by avoiding early exits, aligning dependency graph Python metadata, and refreshing lock files. Also improved documentation for auto-release shell defaults. (ee9eea) (Samuel Oranyeli)
- Ensured that `complete(sort=True)` on Polars LazyFrames maintains the correct row order by explicitly requesting left order preservation in joins. (d4fdf9) (JanakiRam Chittineni)

## Deprecations

- No deprecations in this release.

## Dependency Updates
