# Version v0.32.58

This release delivers major performance improvements and memory optimizations for equi and range joins, especially on large datasets. It also updates dependencies for improved compatibility and reliability, and includes several code refactors for maintainability. Some test logic has been updated to better handle edge cases with embedded NUL characters.

## New Features

- Significantly reduced peak memory usage for equi and range joins with a single equality key by optimizing factorization and sorting logic. For example, memory usage for large joins dropped from 6.66 GiB to 1.53 GiB and from 18.77 GiB to 3.83 GiB in tested cases. (f6930a) (Samuel Oranyeli)
- Improved multi-key equi join performance by building MultiIndexes only over equality keys and optimizing sorting and uniqueness checks. (f6930a) (Samuel Oranyeli)
- Skipped unnecessary data lookups for size aggregations, further reducing memory usage and improving speed. (f6930a) (Samuel Oranyeli)
- Reused sort order as right labels for default RangeIndex joins, eliminating redundant data copying. (f6930a) (Samuel Oranyeli)

## Bug Fixes

- Updated test logic for joins involving embedded NUL characters to ensure compatibility with pandas 3.1.0 and later, where factorization behavior has changed. (f6930a) (Samuel Oranyeli)

## Deprecations

- None in this release.

## Other Changes

- Updated janitor-rs dependency to version 0.6.6 for improved compatibility and consistency across build files. (f6930a) (Samuel Oranyeli)
- Various code refactors to clarify variable names, simplify logic, and improve maintainability. (f6930a) (Samuel Oranyeli)
