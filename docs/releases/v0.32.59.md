# Version v0.32.59

This release improves the handling of missing values in the drop_constant_columns function, ensuring more accurate detection and removal of columns with constant or all-missing values. Documentation has also been updated to clarify this behavior.

## New Features

- No new features were added in this release.

## Bug Fixes

- Improved drop_constant_columns to correctly count missing values, treating different types of null-like objects as a single missing category. This ensures columns with all missing values are properly identified and removed. (401b61) (Senanur Çetin)

## Deprecations

- No deprecations were introduced in this release.
