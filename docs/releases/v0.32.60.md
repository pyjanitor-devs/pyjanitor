# Version v0.32.60

This release focuses on improving the reliability of DataFrame reshaping operations, specifically addressing issues with input data mutation in the `pivot_longer` function. It also includes routine maintenance updates.

## New Features

_No new features were added in this release._

## Bug Fixes

- Fixed an issue in `pivot_longer` where the output could inadvertently modify the input DataFrame. The function now ensures input immutability by copying non-owning ndarray views and shared value buffers, with comprehensive regression tests to prevent similar issues in the future. (3d8d51, Senanur Çetin)

## Deprecations

_No deprecations were introduced in this release._
