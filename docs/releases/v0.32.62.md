# Version v0.32.62

This release focuses on significant performance improvements and expanded test coverage for the pivot_longer functionality, especially when working with homogeneous NumPy columns. Several edge cases and regression scenarios are now better handled, and benchmarking tools have been enhanced for more accurate performance measurement.

## New Features

- Added comprehensive test coverage for pivot_longer, including edge cases, heterogeneous object scalars, and source isolation scenarios. (dd889d) (Senanur Çetin)
- Improved benchmarking tools to separately measure timing and traced memory usage for performance analysis. (dd889d) (Senanur Çetin)

## Bug Fixes

- Ensured correct handling and preservation of heterogeneous object scalars and source isolation in pivot_longer. (dd889d) (Senanur Çetin)
- Fixed issues with dtype compatibility for timestamps and padding in NumPy temporal, complex, and float16 columns during pivot operations. (dd889d) (Senanur Çetin)
- Addressed multi-block source isolation and uneven group handling in pivot operations. (dd889d) (Senanur Çetin)
- Preserved defensive copy guards for single-block sources in pivot operations. (dd889d) (Senanur Çetin)

## Performance Improvements

- Significantly accelerated pivot_longer operations for .value groups with homogeneous NumPy columns, reducing unnecessary data copies and improving overall speed. (dd889d) (Senanur Çetin)
- Avoided redundant copies on fragmented value groups in pivot operations for better memory efficiency. (dd889d) (Senanur Çetin)

## Deprecations

- No deprecations in this release.
