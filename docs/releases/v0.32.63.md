# Version v0.32.63

This release focuses on improving the reliability of DataFrameGroupBy operations, especially when copying, assigning, or mutating grouped data. Several subtle bugs related to stale columns and cached accessors have been addressed, ensuring more predictable and robust behavior when working with groupby objects.

## New Features

- Added a new internal method `_copy_groupby` to safely copy DataFrameGroupBy objects without carrying over stale cached accessors or state. This ensures that copied groupby objects reflect the current DataFrame structure. (700052) (Samuel Oranyeli)

## Bug Fixes

- Fixed an issue where copying a DataFrameGroupBy object (e.g., during assign or rle_id operations) could result in stale columns or KeyErrors due to shared pandas cache and accessors. The cache is now cleared after each column assignment, preventing outdated state from affecting subsequent operations. (700052) (Samuel Oranyeli)
- Resolved a bug in the deprecated groupby mutate method where using copy.copy would retain accessors bound to the original groupby, causing errors in later assign/rle_id/get_columns calls. Now, all cached accessors are dropped when copying, and the cache is cleared after each mutate argument. (700052) (Samuel Oranyeli)

## Deprecations

- The groupby mutate method remains deprecated. Its behavior has been updated to route through the new _copy_groupby logic, but users are encouraged to migrate to supported alternatives. (700052) (Samuel Oranyeli)
