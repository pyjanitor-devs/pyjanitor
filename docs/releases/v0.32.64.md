# Version v0.32.64

This release introduces significant performance improvements and enhanced compatibility for groupby operations, particularly for the `rle_id` function. The changes bring faster execution, better handling of various data types, and improved support for advanced grouping scenarios.

## New Features

- Greatly improved the performance of `groupby.rle_id` by vectorizing operations and reusing the groupby's internal grouping logic. This change speeds up large groupby operations (e.g., 1 million rows / 630k groups: ~172 seconds → ~40 milliseconds), ensures correct handling of `level=` grouping, respects `dropna=False`, and properly assigns IDs even with duplicate index labels. The update also removes a slow apply/stack path and adds tests for time-based grouping, string and nullable dtypes, and dropped nullable keys. (220c90) (Samuel Oranyeli, co-authored by Claude Opus 5.5)

## Bug Fixes

- Fixed issues with `rle_id` when working with string[pyarrow] columns and nullable dtypes by casting change flags to plain bool before cumulative sum. This prevents errors with unsupported dtypes and ensures the ID column is always int64, regardless of value dtype. Also optimized first-row flag calculation for better performance on MultiIndex groupbys. (220c90) (Samuel Oranyeli, co-authored by Claude Opus 5.5)

## Deprecations

- No deprecations in this release.
