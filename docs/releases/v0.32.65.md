# Version v0.32.65

This release introduces a change to the default behavior of the join_agg function, improving consistency and control for users working with join aggregations.

## New Features

- Changed the default value of the return_matched parameter in the join_agg function to False, making the function return only aggregated results by default. (40a68b) (Samuel Oranyeli)
