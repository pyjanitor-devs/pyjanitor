# Version v0.32.66

This release improves the behavior of the adorn formatting functions, ensuring that numeric row identifiers are preserved and not mistakenly formatted as data. It also recognizes a new contributor for their foundational work on adorn functions.

## New Features

- Added Sarra99 to the all-contributors list for their original work on adorn functions. (c5524e) (Cursor Agent)

## Bug Fixes

- Fixed an issue where adorn_pct_formatting, adorn_ns, and adorn_rounding would incorrectly format, count, or round a numeric first column used as a row identifier. Now, the first column is left unchanged, matching the behavior of adorn_totals and adorn_percentages. (978935) (Cursor Agent)

## Deprecations

- No deprecations in this release.
