# Version v0.32.67

This release introduces a significant performance improvement for join operations using keep="any" with same-direction range predicates. The update optimizes how matching rows are found, greatly reducing scan times in large datasets. No bug fixes or deprecations are included in this release.

## New Features

- Improved performance for join operations with keep="any" and same-direction range predicates by introducing an envelope optimization. This change allows the join to avoid scanning the entire window when two range predicates point in the same direction (e.g., both < or both >), resulting in much faster joins on large datasets. The optimization is applied only when data types can be safely negated; otherwise, the previous behavior is retained. Note: keep="any" may now return a later match rather than the first one.
