# Version v0.32.68

This release focuses on significant improvements to the documentation for conditional joins, especially around advanced usage patterns and performance considerations. A comprehensive new example demonstrates how to perform semi-joins and anti-joins with two inequalities, including practical recipes, operator coverage, and performance notes. The documentation is now more thorough, visually clear, and rigorously tested for accuracy.

## New Features

- Added a detailed "staircase" example to the conditional_join documentation, showing how to perform semi-joins and anti-joins with two inequalities using both NumPy and conditional_join. The example includes DataFrame outputs, covers all operator combinations, discusses performance, and is presented as a tip for easy discovery. All code and tables are tested for correctness.
