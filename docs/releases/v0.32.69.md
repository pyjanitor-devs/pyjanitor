# Version v0.32.69

This release introduces a significant performance improvement for conditional joins with specific range predicates, leveraging the new staircase kernel from janitor-rs. It also expands test coverage for various data types and join modes, and updates dependencies to ensure compatibility with the latest janitor-rs features.

## New Features

- Greatly improved performance for conditional_join(..., keep="any") when using exactly two range predicates on numeric, datetime, or timedelta columns. These joins now use the janitor-rs staircase kernel for faster execution. Joins with equality keys, more than two predicates, other keep modes, or non-numeric types continue to use the existing logic. (634249) (Samuel Oranyeli, co-authored by Claude Sonnet 5.5)
- Expanded test coverage for the staircase kernel, including datetime, timedelta, int64 minimum, uint64 above int64 maximum, shuffled indices, and various join modes (inner/left/right). (634249) (Samuel Oranyeli, co-authored by Claude Sonnet 5.5)

## Bug Fixes

- Updated the keep="any" doctest to reflect the new behavior of the staircase kernel, ensuring documentation examples remain accurate. (634249) (Samuel Oranyeli, co-authored by Claude Sonnet 5.5)

## Deprecations

- None in this release.
