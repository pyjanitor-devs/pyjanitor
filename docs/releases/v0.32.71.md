# Version v0.32.71

This release improves the performance and consistency of conditional joins by updating the sorting mechanism to use pandas' default sort behavior. Additional tests have been added to ensure correct handling of tie cases and sorting stability.

## New Features

- Added tests to validate correct handling of tie cases in conditional joins, ensuring reliable results when duplicate values are present. (f36847) (Samuel Oranyeli)
- Introduced tests to exercise and verify the behavior of unstable sorting in conditional joins. (f36847) (Samuel Oranyeli)

## Bug Fixes

- Improved performance and consistency of conditional joins by switching to pandas' default sorting method, addressing issues with previous sorting approaches. (f36847) (Samuel Oranyeli)

## Deprecations

- None.
