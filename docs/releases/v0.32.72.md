# Version v0.32.72

This release focuses on significant improvements to the documentation, particularly around advanced usage of the `join_agg` function for per-day totals over date ranges. The new examples and tips provide clearer guidance and practical advice for users working with date-range aggregations, including performance considerations and links to relevant external resources.

## New Features

- Added comprehensive documentation examples for using `join_agg` to compute per-day totals over date ranges, including step-by-step explanations, input dataframe displays, and links to related Stack Overflow discussions. The documentation now also includes tips on boundary counting, cumulative sum approaches, and performance timing tables with real-world data references.
