# Version v0.32.77

This release improves the handling of grouped data operations, especially around the use of the deprecated by argument in expand and complete. It introduces more robust validation, clearer warnings, and enhanced support for partial fills and categorical data. Several internal cleanups and documentation improvements are also included.

## New Features

- Added support for partial fill_value dictionaries in complete for grouped DataFrames; only specified columns are filled. (8e3cb1) (SumanGouda, Eric Ma)
- complete(by=...) now groups before expanding, ensuring expand does not emit redundant warnings. (8e3cb1) (SumanGouda, Eric Ma)
- Categorical fill values are now only added when pandas does not already treat the column as a category, improving compatibility. (8e3cb1) (SumanGouda, Eric Ma)
- Shared groupby logic between expand and complete, ensuring consistent validation and grouping behavior. (124792) (Eric Ma)

## Bug Fixes

- Fixed complete for grouped frames to accept fill_value dictionaries and suppress unnecessary by warnings. (8e3cb1) (SumanGouda, Eric Ma)
- Improved validation of the deprecated by argument in grouped operations, raising errors for invalid values before emitting deprecation warnings. (71a9d4) (Eric Ma)
- Removed unreachable code and improved docstring formatting for consistency. (71a9d4) (Eric Ma)
- Ensured deprecation warnings for by are emitted at the correct stage, even if expand fails. (9863b2) (Eric Ma)
- Tightened tests for complete to better cover edge cases. (9863b2) (Eric Ma)

## Deprecations

- The deprecated by argument in expand and complete is now validated and will raise errors for invalid values before emitting a FutureWarning, matching DataFrame behavior. (71a9d4, 9863b2, 124792) (Eric Ma)
