# Version v0.32.79

This release focuses on improving the robustness and usability of the complete function, especially when handling group keys and labels of various types. Documentation has also been updated for better clarity.

## New Features

- Documentation updated to keep the developer-learned note beside the complete label note for improved clarity. (ad1712) (Cursor Agent)

## Bug Fixes

- Fixed an issue where grouped complete would drop integer group keys or raise errors when group keys were integers. Now, integer group keys are preserved correctly. (57d9b3) (Cursor Agent)
- Fixed complete(..., explicit=False) to properly handle one-column and non-string labels, preventing errors when labels are integers or when only one column is present. (2fa1be) (Cursor Agent)
- Updated the unreleased changelog entry to cite PR 1861 for better traceability. (13f504) (Cursor Agent)

## Deprecations

- No deprecations in this release.
