# Version v0.32.80

This release focuses on improving the reliability of default value handling in coalesce operations, ensuring that falsy values are correctly validated. No new features or deprecations were introduced in this version.

## New Features

_None in this release._

## Bug Fixes

- Fixed an issue where falsy default values (such as 0, False, or empty strings) were not properly validated in coalesce operations. This ensures that all default values, including falsy ones, are handled as expected. (073ed3) (mayankm00007)
